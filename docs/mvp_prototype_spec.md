# MVP 页面原型说明: 账号急诊室

## 1. 原型目标

本原型用于指导 MVP 开发，优先完成从内容平台引流到用户提交诊断、查看免费报告、留资解锁完整报告的闭环。

设计原则：
- 移动端优先，适配小红书/抖音/微信内置浏览器
- 页面少，路径短，减少解释性内容
- 文案要直接、有痛点、有轻微吐槽感
- 免费结果要足够具体，才能推动用户留资或付费

## 2. 信息架构

页面列表：
- 首页/落地页：`/`
- 诊断表单页：`/diagnosis`
- 生成等待页：`/diagnosis/loading`
- 免费报告页：`/report/:id`
- 解锁页/留资弹窗：`/report/:id#unlock`
- 完整报告页：`/report/:id/full`
- 生成失败页：复用报告页错误态或 loading 错误态

MVP 可不做登录系统，使用报告 id 作为访问凭证。

## 3. 页面 1：首页/落地页

### 3.1 页面目标

让用户在 5 秒内理解：
- 这是一个小红书账号诊断工具
- 它能帮我找到没流量的原因
- 我现在可以免费测一下

### 3.2 首屏模块

主标题：

```text
测测你的小红书账号为什么没流量
```

副标题：

```text
输入账号定位和最近几篇标题，AI 给你生成账号诊断、选题建议和 7 天起号计划。
```

主按钮：

```text
开始免费诊断
```

辅助文案：

```text
不用登录，1 分钟填写，先看免费诊断。
```

首屏视觉建议：
- 左侧或上方为标题和 CTA
- 右侧或下方展示一张“诊断报告预览”
- 移动端报告预览放在 CTA 下方

报告预览内容：
- 账号定位评分：62/100
- 当前最大问题：标题太像自我记录，不像用户搜索问题
- 推荐选题：新手做小红书，先别急着日更

### 3.3 痛点模块

标题：

```text
如果你也卡在这些问题，可以先测一次
```

痛点卡片：
- 发了很多篇，阅读还是几十
- 不知道自己的定位到底清不清楚
- 每天最痛苦的是想选题
- 标题写完自己都不想点
- 想变现，但内容一直像日记

### 3.4 结果说明模块

标题：

```text
诊断后你会拿到什么
```

展示项：
- 账号定位问题
- 近期标题诊断
- 5 个免费推荐选题
- 完整报告可解锁 30 个选题和 7 天发布计划

### 3.5 底部 CTA

文案：

```text
先别急着日更，先看看账号卡在哪里
```

按钮：

```text
开始免费诊断
```

## 4. 页面 2：诊断表单页

### 4.1 页面目标

收集生成诊断报告所需的最小信息，同时让用户觉得填写成本低。

### 4.2 页面布局

顶部：
- 页面标题：账号挂号单
- 进度提示：预计 1 分钟

表单主体：
1. 账号昵称
2. 账号赛道
3. 当前粉丝量
4. 账号目标
5. 目标人群
6. 账号简介
7. 最近 3-5 篇笔记标题
8. 当前最大困惑

底部固定提交按钮：

```text
生成免费诊断
```

### 4.3 字段说明

#### 账号昵称

类型：输入框  
是否必填：否  
占位文案：

```text
例如：阿林的职场成长笔记
```

#### 账号赛道

类型：下拉选择/标签选择  
是否必填：是  
选项：
- 职场成长
- 副业赚钱
- 情绪疗愈
- 读书成长
- 育儿教育
- 美妆穿搭
- 探店本地生活
- AI 工具分享
- 其他

#### 当前粉丝量

类型：单选  
是否必填：是  
选项：
- 0-100
- 100-500
- 500-1000
- 1000-5000
- 5000 以上

#### 账号目标

类型：多选，最多 2 个  
是否必填：是  
选项：
- 涨粉
- 引流私域
- 卖产品/服务
- 打造个人 IP
- 接广告/商务
- 还没想清楚

#### 目标人群

类型：文本输入  
是否必填：是  
占位文案：

```text
例如：想转行互联网运营的 25-30 岁女生
```

#### 账号简介

类型：多行文本  
是否必填：否  
占位文案：

```text
复制你现在的小红书简介，或者简单写一句你想做什么账号
```

#### 最近 3-5 篇笔记标题

类型：多行文本  
是否必填：是  
占位文案：

```text
一行一个标题，至少填 3 个
```

校验：
- 至少 3 行非空标题
- 每个标题不超过 80 字

#### 当前最大困惑

类型：多行文本  
是否必填：是  
占位文案：

```text
例如：不知道为什么阅读量一直很低，感觉标题和选题都没方向
```

### 4.4 表单错误提示

错误提示原则：
- 具体指出缺失项
- 不使用技术化表达

示例：
- 先选一个账号赛道，AI 才知道按哪个方向诊断。
- 至少填 3 个标题，不然很难看出账号问题。
- 写一下你的目标人群，越具体诊断越准。

## 5. 页面 3：生成等待页

### 5.1 页面目标

降低等待焦虑，让用户愿意停留到报告生成完成。

### 5.2 页面内容

主文案：

```text
正在给你的账号挂号
```

动态步骤：
1. 正在读取账号定位
2. 正在拆你的标题病历
3. 正在定位流量卡点
4. 正在生成起号处方

等待提示轮播：
- 标题不是越夸张越好，而是要让目标用户觉得“这说的就是我”。
- 新号前 20 篇别急着变现，先让系统看懂你是谁。
- 选题不是写自己想说什么，而是写用户正在搜什么。

### 5.3 状态

生成中：
- 展示步骤动画和提示

生成成功：
- 自动跳转免费报告页

生成失败：
- 文案：这次诊断没生成成功，可以重新试一次
- 按钮：重新生成
- 辅助按钮：返回修改信息

## 6. 页面 4：免费报告页

### 6.1 页面目标

给出足够具体的诊断，让用户相信完整报告值得解锁。

### 6.2 页面顶部

标题：

```text
你的账号初诊结果
```

副标题：

```text
先看最影响流量的几个问题，完整报告里会给出具体选题和发布计划。
```

核心评分卡：
- 账号体检分
- 定位清晰度
- 标题点击感
- 选题匹配度

示例：

```text
账号体检分：62/100
主要问题：定位能看懂，但标题没有把用户痛点说出来。
```

### 6.3 免费内容模块

模块 1：当前最大问题
- 展示 1-2 条
- 每条包含“问题”和“建议”

模块 2：标题问题总结
- 展示对近期标题的整体诊断
- 可展示 1 个标题改写示例

模块 3：推荐选题
- 展示 5 个选题
- 每个选题展示标题和适合原因

### 6.4 解锁引导模块

标题：

```text
完整报告已经生成
```

解锁内容清单：
- 完整账号诊断
- 30 个可直接发的小红书选题
- 20 个标题改写
- 7 天发布计划
- 封面文案
- 评论区互动话术

按钮：

```text
解锁完整报告
```

辅助文案：

```text
MVP 阶段可先留微信领取，后续开放在线支付。
```

## 7. 页面 5：解锁/留资弹窗

### 7.1 页面目标

用低成本方式验证完整报告需求，并沉淀可触达用户。

### 7.2 弹窗内容

标题：

```text
领取完整账号处方
```

说明：

```text
留下微信，我们会把完整报告发给你。MVP 内测期优先人工精修。
```

字段：
- 微信号，必填
- 是否愿意接受人工诊断，单选

按钮：

```text
提交并领取完整报告
```

提交成功态：

```text
已收到。你可以先查看网页版完整报告，我们也会按微信号同步给你。
```

### 7.3 后续付费版本替换

当验证付费需求后，此弹窗可改为：
- 支付二维码
- 兑换码输入
- 微信/支付宝支付

## 8. 页面 6：完整报告页

### 8.1 页面目标

完整交付用户期待的诊断结果，让用户愿意收藏、转发或复购。

### 8.2 页面结构

顶部：
- 报告标题
- 生成时间
- 账号赛道
- 账号目标

模块：
1. 账号体检总评
2. 当前最影响流量的 3 个问题
3. 账号定位优化建议
4. 目标人群重新定义
5. 内容选题方向
6. 30 个可直接发布的选题
7. 最近标题逐条诊断
8. 20 个标题改写版本
9. 7 天发布计划
10. 封面文案建议
11. 评论区互动话术
12. 下一步行动清单

### 8.3 操作按钮

主要操作：
- 复制报告
- 复制 30 个选题
- 重新诊断

MVP 可先做复制按钮，不做 PDF 导出。

## 9. 空态与异常态

### 9.1 报告不存在

文案：

```text
没有找到这份报告，可能链接不完整或报告已过期。
```

按钮：

```text
重新开始诊断
```

### 9.2 报告生成中

如果用户刷新报告页但还没完成：
- 展示生成中状态
- 每 3-5 秒轮询一次

### 9.3 AI 返回内容异常

文案：

```text
这次报告内容不完整，可以重新生成一次。
```

按钮：
- 重新生成
- 返回修改信息

## 10. 移动端设计要求

- 页面宽度按 375px 优先设计
- 主 CTA 在关键页面底部固定
- 表单字段高度足够，便于手机输入
- 卡片圆角不超过 8px
- 避免大面积装饰和复杂动效
- 报告内容使用清晰分段，避免一整屏大段文字
- 所有按钮文案不超过一行

## 11. MVP 不做范围

第一版不做：
- 用户登录注册
- 支付自动回调
- PDF 导出
- 多账号管理
- 历史报告列表
- 复杂后台权限
- 小红书账号自动抓取
- 浏览器插件

## 12. 验收标准

- 用户从首页可以完整走到免费报告
- 表单校验可阻止无效输入
- AI 生成期间有等待反馈
- 免费报告页展示具体诊断，不是空泛建议
- 用户可以提交微信领取完整报告
- 完整报告页可查看所有模块
- 移动端 375px 宽度下无明显溢出和遮挡
